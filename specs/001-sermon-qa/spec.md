# 功能規格：主日講道 QA 留言板

- **規格編號**：001-sermon-qa
- **狀態**：草稿（待確認）
- **建立日期**：2026-11-02

## 1. 背景與目標

主日講道時，會友常有疑問或感動，但缺乏即時、低壓力的管道表達。ECHO 讓會友在聚會中掃描 QR code 進入該場次的留言板，匿名提出問題或分享心得；牧者可在聚會中或會後查看並回應，所有場次的 QA 長期保存。

**成功指標**

- 會友從掃碼到送出第一則留言 ≤ 30 秒。
- 牧者能在單一畫面中依熱門度找到待回應的問題。
- 任一歷史場次的 QA 在場次結束後仍可完整瀏覽與匯出。

## 2. 角色

| 角色           | 說明                                                                                     | 登入方式                       |
| -------------- | ---------------------------------------------------------------------------------------- | ------------------------------ |
| 會友 (Member)  | 掃碼進入，匿名留言、附議                                                                 | 免登入（背景自動建立匿名身分） |
| 管理者 (Admin) | 牧者或同工，**只有一種身分、權限都相同**：建立/開放/結束/刪除場次、回覆、隱藏留言（D12） | Email + 密碼                   |

> 管理帳號由系統管理者在 Supabase 後台建立，不開放自行註冊。可以只開一個共用帳號，也可以每人一個，權限都一樣。
>
> **QR code 畫面人人都能開**（AC5.12）：負責投影的人員不需要管理帳號。

## 3. 名詞定義

- **場次 (Session)**：一次主日講道。有標題、講員、經文、日期，以及狀態 `草稿 → 開放中 → 已結束`。
- **場次碼 (Code)**：6 碼英數短碼（排除易混淆字元 0/O/1/I/L），組成 QR code 網址。
- **留言 (Post)**：會友發出的內容，提問、感動、回應都可以，**不另外分類**（分類列入 B-10）。
- **附議 (Upvote)**：會友對某則留言表示「我也想知道 / 有同感」，每個裝置每則一次。
- **回覆 (Reply)**：管理者（通常是牧者）對某則留言的回應，公開顯示於該留言下方。

## 4. 使用者故事與驗收條件

> 畫面、版型與互動細節見 [ux.md](./ux.md)。會友端與管理端為**不同入口與版型、共用留言卡片元件**（ux.md §1）。

### US1 會友進入場次留言板（P1）

會友掃描投影或週報上的 QR code，直接看到該場次的留言板。

- **AC1.1** Given 場次為「開放中」，When 會友開啟 QR code 網址，Then 顯示場次標題、講員、經文、日期，以及所有未隱藏的留言，且可以留言。
- **AC1.2** Given 場次為「已結束」，When 會友開啟網址，Then 可瀏覽留言與回覆，但留言輸入框與附議按鈕停用，並顯示「本場次已結束」。
- **AC1.3** Given 場次為「草稿」或場次碼不存在，When 會友開啟網址，Then 顯示「找不到此場次」，不洩漏草稿內容。
- **AC1.4** 會友不需要任何登入動作；系統在背景建立匿名身分，同一裝置/瀏覽器再次進入時視為同一人。
- **AC1.5** 首頁提供「輸入場次碼」欄位，供無法掃碼的會友手動輸入。
- **AC1.6** 會友端所有頁面（首頁、留言板、過去場次）在手機、平板、電腦上都可完整使用（ux.md §2.1）。
- **AC1.7** **固定 QR**：`/now` 永遠帶到目前開放中的場次（多場同時開放時取日期最近、建立最晚的一場）；沒有開放中的場次時，顯示首頁並提示「目前沒有開放中的場次」。可長期印在海報、桌卡上，不用每週更換。

### US2 會友發表留言（P1）

- **AC2.1** 會友輸入內容（1–500 字），可選填暱稱（≤ 20 字），送出後立即出現在留言板。
- **AC2.2** 未填暱稱時顯示為「匿名」。暱稱記憶於該裝置，下次自動帶入。
- **AC2.3** 同一身分 1 分鐘內最多送出 5 則；超過時顯示「留言太頻繁，請稍後再試」。
- **AC2.4** 會友送出後**不能刪除**自己的留言（D9）。不當內容由管理者隱藏（US7）。
- **AC2.5** 會友不可編輯留言。
- **AC2.6** ~~自己的留言有「我的留言」標示~~（2026-11-03 取消，見 D11）。會友端看不出哪幾則留言出自同一人。

### US3 會友附議（P1）

- **AC3.1** 會友點擊附議，該留言附議數 +1，按鈕呈已附議狀態；再點一次取消。
- **AC3.2** 同一身分對同一留言最多附議一次（由資料庫保證）。
- **AC3.3** 會友可切換排序：「最新」（預設）/「最多附議」。

### US4 即時更新（P1）

- **AC4.1** 他人新增的留言、牧者回覆、附議數變化，在 3 秒內出現在所有開啟中的畫面，不需重新整理。
- **AC4.2** 留言被隱藏時，3 秒內從所有會友畫面消失。
- **AC4.3** 網路中斷恢復後，自動重新同步最新資料。

### US5 管理者登入與場次管理（P1）

- **AC5.1** 管理者以 Email + 密碼登入後台；非管理帳號（含匿名身分）無法進入後台。
- **AC5.2** 可建立場次（標題、日期為必填；講員、經文、自動結束時間選填），系統自動產生場次碼。表單有兩個送出選項：「建立並開放留言」（直接開放）與「先存成草稿」。日期預設為下一個主日（當天是主日則為當天），講員預設為上一場的講員。建立後進入該場次頁，立即顯示 QR code 與「全螢幕投影 QR」「複製連結」。
- **AC5.11** 同一時間可以有多個「開放中」場次（例如主日早堂、午堂各一場）；固定 QR（AC1.7）會帶到最近日期的那一場。
- **AC5.3** 可將場次「開放」與「結束」；已結束可重新開放。
- **AC5.10** 管理端所有功能（含講台模式、回覆、隱藏、場次設定、瀏覽過去場次）在手機、平板、筆電上都可完整使用；筆電版以左側欄切換場次（ux.md §2.1）。
- **AC5.9** 可為場次設定「自動結束時間」（可不設、可修改、可清除）。到時間後場次自動變為「已結束」，即使當下沒有人開著後台；會友端在開放期間顯示「留言開放至 12:30」。重新開放時會清除自動結束時間。
- **AC5.4** 場次頁面顯示 QR code、完整網址，可複製網址、下載 QR code 圖檔（PNG），並可「全螢幕投影 QR」供聚會開始時投影在大螢幕。
- **AC5.5** 場次列表依日期由新到舊，顯示狀態、留言數、待回應問題數。
- **AC5.6** 管理者可刪除場次（連同所有留言，需輸入場次標題確認）。
- **AC5.12** **會友端也能開全螢幕 QR**：留言板頁首有「QR code」按鈕，不需登入，顯示與管理端「全螢幕投影 QR」相同的畫面（場次標題、QR、場次碼、網址），方便負責投影的人員直接投影。（2026-11-04，D12）
- **AC5.7** 管理者開啟會友網址時，看到的是一般會友畫面（不含任何管理按鈕），頂部多一條提示列可前往該場次管理頁。
- **AC5.8** 場次管理頁提供「以會友身分預覽」。

### US6 管理者回應留言（P1）

- **AC6.1** 後台場次頁可篩選：待回應 / 全部 / 已隱藏；排序：最多附議 / 最新 / 最舊。
- **AC6.2** 管理者可對任一留言回覆（1–2000 字），回覆公開顯示於該留言下方，標示帳號的顯示名稱（例：王牧師）與時間。
- **AC6.3** 一則留言可有多則回覆；管理者可編輯、刪除回覆。
- **AC6.4** 有文字回覆的留言標示為「已回應」，在會友端也可看到此標示。**只有文字回覆才算已回應**，牧者在台上口頭回答不另外標記。
- **AC6.5** 場次「已結束」後管理者仍可回覆（會後補充回應）。

### US7 隱藏不當留言（P1）

- **AC7.1** 管理者可隱藏/取消隱藏任一留言；被隱藏的留言會友端看不到，後台仍可在「已隱藏」中看到。
- **AC7.2** 記錄由誰、於何時隱藏。
- **AC7.3** 隱藏不需確認，改為 5 秒內可「復原」。

### US8 歷史場次保存與匯出（P2）

- **AC8.1** 所有場次與留言永久保存，除非管理者刪除場次。
- **AC8.2** 已結束場次的網址持續有效（唯讀，見 AC1.2）。
- **AC8.3** 後台可將單一場次 QA 匯出為 Markdown 與 CSV（不含已隱藏留言，可選擇包含）。
- **AC8.4** 會友端首頁顯示場次列表：「進行中」（開放中的場次）置頂，下方為「過去的場次」（已結束，依日期由新到舊，每次載入 20 筆、可載入更多）。草稿不顯示。點進去即為該場次的唯讀留言板（AC1.2）。

### US9 講台模式（P1）

牧者在講台上用平板（或接上投影機的裝置）直接看會友的留言並回應。負責投影的同工不一定是講者本人，也不一定有管理帳號，所以**會友端也可以放大**（唯讀）。

- **AC9.1** 在場次管理頁點任一則留言（或該留言的「放大」按鈕），即在**同一台裝置**上全螢幕顯示該則的問題卡片。
- **AC9.2** 卡片顯示「會友留言」、內容（大字）與附議數；**一律不顯示暱稱**。
- **AC9.3** 可切換上一則／下一則，順序依進入時的篩選與排序；鍵盤 `←` `→` 切換，`Esc` 離開。
- **AC9.4** 卡片上有「文字回覆」按鈕，開啟回覆編輯器（AC6.2）。
- **AC9.5** 卡片的附議數即時更新；目前這則被隱藏時，自動切換到下一則。
- **AC9.6** 會友端（含過去場次）每則留言有「放大」按鈕，頁首有「投影」按鈕（從目前排序的第一則開始）；顯示與管理端相同的小卡，可上一則／下一則、鍵盤操作、全螢幕，但**沒有「文字回覆」**，也只看得到公開的留言。
- **AC9.7** 會友端的放大網址為 `/s/:code/stage?post=<id>`，不需登入，可直接分享給負責投影的同工。

## 6. 非功能需求 (NFR)

- **NFR-01 效能**：手機 4G 下首次載入 ≤ 3 秒；單場次支援 300 則留言流暢捲動。
- **NFR-02 併發**：單場次同時 200 人在線（注意 Supabase 免費方案 Realtime 連線上限，見 plan 風險）。
- **NFR-03 安全**：所有權限由資料庫 RLS 強制；會友無法讀取草稿、已隱藏留言或任何身分資訊（包括留言的匿名作者代碼）。
- **NFR-04 可用性**：行動優先、長者友善（見憲章）；響應式支援 360px–1920px 寬度（ux.md §2.1）。
- **NFR-05 部署**：前端為靜態網站部署於 GitHub Pages；後端僅使用 Supabase，無自建伺服器。
- **NFR-06 成本**：只使用 Supabase 與 GitHub 的**免費方案**，不得使用任何需要付費才能啟用的功能（D10）。可能產生費用的項目一律列入 §7.1。

## 7. 範圍外 / 後續待辦 (Backlog)

- **B-01 私密提問**：會友勾選「只給牧者看」，不公開於留言板。
- **B-02 會友互相回覆**：留言底下的討論串。
- **B-03 人機驗證**：匿名登入加上 Cloudflare Turnstile，防止大量灌水。
- **B-04 多教會 / 多組織**。
- **B-05 不雅字詞自動過濾**。
- **B-06 手機遙控大螢幕**：投影電腦開啟投影頁，牧者用手機選擇要投影的留言，大螢幕即時切換。
- **B-07 會友端「牧者正在台上回應」提示**（需 B-06）。
- **B-08 口頭回應標記**：把台上口頭回答過的問題標記為已回應（目前決定只有文字回覆才算）。
- **B-09 講道投影片上傳**：牧者可為場次上傳投影片（PDF），會友在留言板（含過去場次）可線上瀏覽與下載。預計使用 Supabase Storage，需另寫規格（檔案大小上限、可見時間、免費方案 1 GB 儲存空間的用量）。
- **B-10 留言分類**：會友留言時可選「問題」或「心得」，並可依類型篩選（2026-11-02 決定先不做，避免太複雜）。
